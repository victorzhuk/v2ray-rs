# Spec Delta: geodata-management

## ADDED Requirements

### Requirement: Geodata files live in the cache directory
The system SHALL place downloaded geodata files and the geodata index under the active profile's `cache_dir`, so that geodata can be regenerated by deleting the cache without touching user-authored data.

#### Scenario: Geodata downloads land in cache_dir
- **WHEN** the system downloads `geoip.dat`/`geosite.dat` (or `.db` files for sing-box)
- **THEN** the files SHALL be written under `cache_dir/geodata/` and SHALL NOT appear under `data_dir`

#### Scenario: Geodata index lives in cache_dir
- **WHEN** the geodata index is rebuilt
- **THEN** the index SHALL be written under `cache_dir/geodata-index/`

#### Scenario: Geodata is profile-isolated
- **WHEN** the same user runs the binary first with `--profile production` and then with `--profile development`
- **THEN** each profile SHALL maintain its own copy of the geodata files and index
